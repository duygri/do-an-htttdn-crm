# Customer diagrams

Customer diagrams use the same layout as the Admin diagrams: each diagram type has separate PlantUML sources and rendered images.

```text
customer/
├── use-case/
│   ├── plantuml/  # Customer use-case source
│   └── images/    # Rendered Customer use-case diagrams
└── sequence/
    ├── plantuml/  # Customer sequence-diagram sources
    └── images/    # Rendered Customer sequence diagrams
```

The detailed Customer use-case specifications are maintained separately in [`../../use-cases/customer/customer-use-case-specifications.docx`](../../use-cases/customer/customer-use-case-specifications.docx).
