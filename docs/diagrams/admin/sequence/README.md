# Admin sequence diagrams

This directory contains the Admin sequence-diagram assets grouped by format:

- `source/` — original Visual Paradigm `.vpp` files.
- `plantuml/` — PlantUML source files used for review and regeneration.
- `images/` — rendered PNG diagrams.

The revenue-reporting flow covers revenue by time period, best-selling products, and profit reporting for Admin Sales. Its primary files are:

- `source/12-sales-revenue-reporting.vpp`
- `plantuml/12-sales-revenue-reporting.puml`
- `images/12-sales-revenue-reporting.png`
