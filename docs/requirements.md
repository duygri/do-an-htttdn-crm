# Requirements and task mapping

The project requirements are based on the team task sheet and the 40 GitHub Issues in this repository.

## Parts

| Part | Issue range | Scope |
| --- | --- | --- |
| Part I | I-01 to I-16 | Analysis, design, documentation, testing, and reporting |
| Part II | II-01 to II-12 | Database implementation and Admin interface |
| Part III | III-CRM-01 to III-CRM-12 | CRM manager and customer workflows |

## Execution sprints

| Sprint | Focus |
| --- | --- |
| Sprint 1 | Analysis, diagrams, ERD, data dictionary, wireframes, and database foundation |
| Sprint 2 | Database implementation, authentication, RBAC, Admin, and CRM features |
| Sprint 3 | Integration, test cases, backup or restore verification, documentation, report, and demo |

## Definition of Done

A task can be marked as done only when:

- The requested work is implemented or documented.
- The stated deliverable exists in the repository or is linked from the Issue.
- The result has been checked or tested.
- The related Pull Request has been reviewed and merged.
- The GitHub Issue is updated with evidence where appropriate.
